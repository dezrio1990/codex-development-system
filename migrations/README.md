# Контракт заметок миграции

Каждая заметка описывает ровно один соседний переход и хранится под именем
`<from>-to-<to>.md`, например `1.0.0-to-1.1.0.md`. Обе части имени —
опубликованные стабильные SemVer-выпуски, а `to` строго новее `from`.

## Обязательная структура

Заметка содержит следующие русскоязычные разделы:

- критические (breaking) изменения;
- новые и удалённые обязательства;
- влияние на документацию, код и CI;
- предварительные условия;
- пошаговое применение;
- фактические команды проверки;
- откат.

Заметка не является утверждённым планом и не даёт скрипту права на изменение
проекта. `Sync-ProjectRules.ps1` включает все соседние заметки в накопительный
анализ, после чего создаёт локальный Draft-план. Только пользователь меняет
статус этого плана на `Approved`; любое изменение проекта или выпуска требует
нового анализа и утверждения.

Если для соседнего перехода заметки нет, анализ выводит явное предупреждение и
детерминированный файловый diff. Отсутствие заметки не отключает проверку
целостности выпуска, локальных конфликтов, повторный preflight, binding
утверждённого плана или файловый rollback.
