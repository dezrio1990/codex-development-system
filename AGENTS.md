# Codex Development System

- Пользователь утверждает архитектуру, стек и план до существенной реализации.
- Рабочая редакция находится в `current/`; опубликованные версии — в `versions/`.
- Папки опубликованных версий неизменяемы.
- Документация ведётся на русском языке или сопровождается русским пояснением.
- Субагенты подключаются только тогда, когда специализация существенно улучшает качество или скорость.
- Исполняемый код приложения проверяется тестами и code review; документация проходит один содержательный просмотр.
- Новая версия правил и обновление проекта требуют явного согласования пользователя.
