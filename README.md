# Codex Development System

Центральный репозиторий правил качественной разработки проектов с Codex.

## Модель версий

`current/` содержит будущую редакцию, а `versions/<version>/` — полный самостоятельный снимок опубликованных правил. Снимок не изменяется после публикации: исправление требует нового номера версии. Прикладной проект выбирает версию явно и может оставаться на ней до согласованной миграции.

Официальный remote: `https://github.com/dezrio1990/codex-development-system`.

## Проверка основы

```powershell
pwsh -NoProfile -File .\tests\TestHarness.ps1 .\tests\Common.Tests.ps1
```

Контракты данных расположены в `schemas/`. Изменяемые статусы выпусков находятся в `support.json`.
