# Журнал изменений

## 1.0 — 2026-09-14

- Добавлены общие правила разработки и обязательные согласования пользователя.
- Добавлены девять специализированных ролей: UX, UI, Frontend, Backend, Android, iOS, .NET MAUI, Debugger и Code Reviewer.
- Добавлены базовые шаблоны проектной документации.
- Добавлены профили .NET, Web, Android, iOS и .NET MAUI.
- Добавлена инструкция подключения правил к новым и существующим проектам.
- Удалена прежняя исполняемая инфраструктура PowerShell, поскольку она несоразмерна назначению репозитория документации.

Опубликованные версии неизменяемы. Следующее содержательное исправление будет выпущено под новым номером.
