# Развёртывание

## Предварительные условия

Укажите утверждённую среду, владельца, артефакт, конфигурацию, миграции и проверки.

## Порядок и откат

Опишите воспроизводимые шаги, контрольные точки, условия остановки и безопасный
откат. Production-развёртывание требует отдельного явного утверждения пользователя.

## Фактический результат

Заполняйте после выполнения: команда, время, результат, отклонения и ссылки на
доказательства.
