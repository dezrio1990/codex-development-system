# Наблюдаемость

## Сигналы и владельцы

Опишите метрики, логи, трассировки, пороги, владельца и действие в ответ на сигнал.
Alert создаётся только при наличии владельца и понятного ответного действия.

## Конфиденциальность и проверка

Не записывайте секреты и лишние персональные данные. Фиксируйте фактически
проверенные дашборды, alerts и ограничения покрытия.
