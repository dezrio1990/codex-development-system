# Безопасность

## Модель угроз и данные

Опишите активы, границы доверия, данные, угрозы, меры и остаточный риск.

## Проверки и зависимости

Фиксируйте только выполненные проверки; для зависимостей укажите лицензию,
сопровождение, уязвимости, совместимость и стоимость замены до согласования.

## Секреты

Секреты не хранятся в репозитории, примерах и логах. Укажите разрешённый механизм
выдачи и ротации без записи самого секрета.
