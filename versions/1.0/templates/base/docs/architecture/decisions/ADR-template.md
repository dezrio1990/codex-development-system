# ADR: краткое название решения

## Контекст

Опишите проблему, требования, ограничения и почему решение требуется сейчас.

## Варианты

Сравните реальные варианты по качеству, рискам, стоимости и обратимости.

## Решение

Укажите выбранный вариант, пользователя, утвердившего решение, и дату утверждения.

## Последствия

Зафиксируйте выгоды, компромиссы, миграцию, тесты и документацию.

## Условия пересмотра

Укажите измеримый триггер, владельца и следующий шаг. Существенные будущие
абстракции должны ссылаться на утверждённые ТЗ, roadmap или ADR.
