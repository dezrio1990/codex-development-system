# Локальная копия правил проекта

## Закреплённая версия

Правила в `.codex/rules/` — локальная копия выбранной неизменяемой версии.
Файл `.codex/codex-rules.json` фиксирует источник, номер версии и выбранные
профили. Локальные решения проекта хранятся в документации проекта. Переход на
другую версию выполняется только после сравнения Git diff и явного согласования
пользователя.

## Приоритет документации

Проектная документация уточняет контекст, требования и решения проекта и имеет
приоритет для этих конкретных фактов. Она не отменяет глобальную политику:
согласование пользователя, качество, безопасность и языковые правила обязательны.

## Восстановление контекста

Сначала прочитайте `.codex/codex-rules.json`, `.codex/rules/base.md` и
`AGENTS.md`, затем `docs/status/current.md`, активный план,
связанные требования и ADR. После проверки Git-состояния зафиксируйте
противоречия, риски и следующий шаг. Перед существенным новым этапом получите
явное согласование пользователя.
