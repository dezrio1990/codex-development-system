# Правила проекта {{PROJECT_NAME}}

Этот файл дополняет применимые глобальные правила и не отменяет их. Перед началом
работы прочитайте `docs/status/current.md`, активный план, связанные требования и
ADR, затем проверьте Git-состояние и кратко зафиксируйте риски и следующий шаг.

Существенный этап начинается только после явного утверждения пользователя:
требования, архитектура, стек, значимые зависимости и план этапа согласуются
заранее. Документы остаются на русском языке. Не расширяйте scope без записи в
backlog и нового согласования.

Следуйте владению файлами из активного плана. По завершении обновите status,
фактические проверки, риски, отклонения и следующий шаг. Пользователь является
единственным утверждающим лицом для документов со статусом `Approved`.
