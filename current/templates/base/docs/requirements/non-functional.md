# Нефункциональные требования

## Категории

Используйте стабильные идентификаторы `NFR-###` для общих качественных свойств,
`SEC-###` для безопасности, `ACC-###` для доступности и `OPS-###` для эксплуатации.
Опишите измеримые требования к производительности, надёжности, безопасности,
доступности, приватности, совместимости и наблюдаемости. Допустимые приоритеты:
`Must`, `Should`, `Could`, `Won't now`.
