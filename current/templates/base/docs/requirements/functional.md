# Функциональные требования

## Правила записи

Используйте стабильные идентификаторы `FR-###` для функциональных сценариев и
`UX-###` для требований к пользовательскому опыту. Каждое требование содержит
формулировку, приоритет, проверяемые критерии приёмки, источник, статус и ссылки.
Допустимые приоритеты: `Must`, `Should`, `Could`, `Won't now`. Реализация
допускается только для утверждённых требований из текущего scope.
