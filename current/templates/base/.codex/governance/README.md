# Управление правилами проекта

## Установленный снимок правил

Правила в `.codex/governance/` — vendored-копия выбранного неизменяемого выпуска.
`manifest.json` фиксирует `{{RULES_VERSION}}`, `{{RULES_COMMIT}}`,
`{{CONTENT_HASH}}` и `{{OVERLAYS_JSON}}`. Не редактируйте этот снимок вручную:
локальные решения проекта хранятся в документации проекта, а изменение версии
выполняется только через утверждённый план миграции.

## Приоритет документации

Проектная документация уточняет контекст, требования и решения проекта и имеет
приоритет для этих конкретных фактов. Она не отменяет глобальную политику:
согласование пользователя, качество, безопасность и языковые правила обязательны.

## Восстановление контекста

Сначала прочитайте `AGENTS.md`, затем `docs/status/current.md`, активный план,
связанные требования и ADR. После проверки Git-состояния зафиксируйте
противоречия, риски и следующий шаг. Перед существенным новым этапом получите
явное согласование пользователя.
